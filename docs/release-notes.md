# Newbie Launcher 0.1.37

Microsoft sign-in now becomes the account you play with.

## Microsoft accounts

- Finishing Microsoft sign-in immediately makes that account the **active player**, even when an offline or TLauncher profile was already selected.
- The next launch uses the Microsoft profile name, UUID, XUID and Minecraft access token, so licensed and online-mode servers see that player.
- Refreshing an existing Microsoft token keeps your current account selection instead of switching accounts.
- The confirmation toast now names the active account so it is clear who will join the game.
