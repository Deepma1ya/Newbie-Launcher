# Newbie Launcher 0.1.16

Themed dropdowns.

## Changed

- Replaced the native select menus with a custom dropdown that matches the launcher.
- Rounded trigger and panel, dark elevated surface, grass selection, check mark and hover states.
- Dropdowns are rendered above modals so they are never clipped by scroll containers.
- Full keyboard support: arrow keys, Home/End, Enter/Space, Escape and outside-click close.
- Applied everywhere: Browse filters, create/change instance, loader versions, Java runtime, mod version and install target, library instance and backup frequency.

Everything from 0.1.15 (Bedrock support) and earlier is included.
